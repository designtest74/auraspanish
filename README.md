


# Aura Spanish — Interactive Language Learning Web App

An interactive, web-based educational application built to support Spanish language learning for primary pupils (UK MFL curriculum framework). Designed with accessibility at its core, the app features a dedicated **Focus Mode** to provide a low-stimulation interface tailored for ADHD and autistic learners.

---

## 🌟 Key Features

- **Interactive Spanish Vocabulary Units:** Engaging lessons focused on foundational topics (colors, vocabulary, and basic conversational structures).
- **Accessibility & Focus Mode:** A single-click toggle switch that simplifies the interface, reduces visual noise, and optimizes contrast/animations for neurodivergent students.
- **Student Progress & Practice:** Interactive activities with instant visual feedback to reinforce learning.
- **Lightweight & Fast:** Single-page application structure (`index.html`) optimized for fast loading and seamless deployment via GitHub Pages.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3:** Modern, responsive design with custom styling for accessible color contrast and typography.
- **JavaScript (Vanilla / React):** Dynamic UI state management for interactive exercises and mode switching.
- **GitHub Pages:** Continuous delivery and hosting.
